商家扫码登录 API

独立 Web 可以用 API Key 调用以下接口，登录状态和二维码由同一台服务器上的浏览器维护。

接口用途
GET /v1/merchant/status获取 authenticated、场次和未登录时的 qrImage
POST /v1/merchant/login启动或刷新扫码登录
POST /v1/merchant/logout注销共享商家会话
curl
curl -H 'X-API-Key: 你的Key' 'http://localhost:8766/v1/merchant/status'
curl -X POST -H 'X-API-Key: 你的Key' 'http://localhost:8766/v1/merchant/login'

未登录时响应中的 qrImage 为 data:image/png;base64,...，可直接设为图片的 src。二维码尚未生成时该字段可能为 null，继续轮询即可。商品查询返回 409 时弹出扫码窗口，轮询状态直到 authenticated: true，随后关闭窗口并重试查询。

API Key 请放在自己的 Web 后端；公开网页代码中不要写入共享 Key。跨域浏览器调用可配置服务环境变量 WEB_ORIGINS。

开始使用

先在上方创建 API Key，并确保商家已扫码登录。每个 API 请求都需要带 X-API-Key 请求头；服务地址为 http://localhost:8766。

浏览器地址栏无法设置自定义请求头。请使用 Python、curl 或支持添加请求头的 API 工具调用。

Python 完整示例

python · requests
import requests

base_url = "http://localhost:8766"
headers = {"X-API-Key": "替换为后台创建的Key"}

response = requests.get(
    f"{base_url}/v1/goods",
    params={"ids": "1024677243708"},
    headers=headers,
    timeout=60,
)
response.raise_for_status()
result = response.json()
for goods in result["goodsList"]:
    print(goods["goodsId"], goods["soldQuantity"], goods["soldQuantityTip"])

GET/v1/shows

获取当前账号可添加商品的直播场次。查询商品可传其中的 showId；省略时默认使用第一场。

curl
curl -H 'X-API-Key: 你的Key' \
  'http://localhost:8766/v1/shows'
响应示例
{"shows":[{"showId":"20261105_1080238172_01","title":"直播场次标题","time":"11/05 17:09"}]}

GET/v1/goods

按商品 ID 查询。ids 必填，可传一个或多个 10–20 位商品 ID；多个 ID 用逗号分隔。showId 可选。

查询参数必填说明
ids是商品 ID 自动按每批最多 800 个查询，例如 1024677243708,1024614545320
showId否指定当前可编辑场次；省略时使用第一场
curl
curl -H 'X-API-Key: 你的Key' \
  'http://localhost:8766/v1/goods?ids=1024677243708,1024614545320'

POST/v1/goods/query

批量查询商品。请求体为 JSON；goodsIds 必填，可以是 ID 数组或以逗号、空格、换行分隔的字符串。showId 可选。

curl · application/json
curl -X POST 'http://localhost:8766/v1/goods/query' \
  -H 'X-API-Key: 你的Key' \
  -H 'Content-Type: application/json' \
  -d '{"goodsIds":[1024677243708,1024614545320]}'

指定直播场次时，在 JSON 中加入 "showId":"从 /v1/shows 获取的场次 ID"。超过 800 个 ID 时自动分批查询，合并为一次响应；接口只检查商品信息，不执行确认添加。

返回结果与字段

成功时返回 HTTP 200。个别商品无法添加时，原因会出现在 failures 中。

示例响应 · 商品对象已精简
{
  "showId": "20261105_1080238172_01",
  "requestedCount": 1,
  "successCount": 1,
  "failureCount": 0,
  "batchCount": 1,
  "goodsList": [{
    "goodsId": 1024677243708,
    "title": "商品名称",
    "price": 5290,
    "priceYuan": 52.9,
    "stock": 48000,
    "soldQuantity": 106,
    "soldQuantityTip": "已拼0单"
  }],
  "failures": [],
  "source": "browser"
}
字段说明
price / priceYuan价格，分别以分 / 元表示
soldQuantity平台返回的销量数值
soldQuantityTip平台返回的“已拼”显示文本，与销量分别展示
failures未成功的商品 ID 和原因
batchCount实际拆分的查询批数，每批最多 800 个 ID
sourcebrowser 浏览器页面查询（所有批次均采用此方式）

错误处理

状态码含义处理方式
400ID 或场次参数不合法检查格式、数量、场次
401API Key 无效或已撤销检查请求头或新建 Key
409商家登录失效在本后台扫码登录后重试
422请求体格式错误检查 JSON 与必填字段
503浏览器或上游页面暂不可用稍后重试，检查后台状态
登录失效示例 · HTTP 409
{"detail":{"code":"LOGIN_REQUIRED","message":"商家登录已失效，请在管理后台扫码","adminUrl":"/admin"}}
